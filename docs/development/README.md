# Development records

- [Roadmap](./ROADMAP.md): project scope, implementation stages, and outstanding
  acceptance and release gates.
- [Checkpoint](./CHECKPOINT.md): current coordination context, dated evidence,
  historical approvals, and remaining validation limits.

These records are retained for maintainers and coding agents, not as a getting
started guide. Dated evidence and past approvals do not automatically establish
current authority or runtime readiness. Before project work, follow the active
instructions in the checkout's `AGENTS.md` and read both records.
